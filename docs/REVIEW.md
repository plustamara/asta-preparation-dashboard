# Review notes

## What I changed and why

Acceptance criterion 10 was vague. It said controls can be used with the keyboard, but not which keys. I changed it so it says controls can be reached with Tab and activated with Enter or Space, and show a visible focus indicator. Now I can test it by hand.

## Ideas I considered and did not add

1. Removing the complete and undo button. I kept it, because it is one of the three required features and the progress count depends on it.
2. A skills log for Asta. I did not add it to version 1, because the PRD allows exactly three features and this would be a new one. It could be an idea for version 2.
